# Knowledge Engine Phase Planning — Design Doc

## Context

Knowledge Engine（V1.6~V2.0）构建企业级知识引擎。5 个版本规划，复用 7 章节模板。

## Goals

产出 5 个文档：V1.6 文档解析、V1.7 OCR/多模态、V1.8 Hybrid Search、V1.9 ReRank/Citation/Cache、V2.0 Memory+知识库

## Design Decisions

基于路线图描述推演，引用 Elasticsearch/Milvus/Unstructured 等开源方案。
