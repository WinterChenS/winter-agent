## 3. Phase 拆分

| Phase | 名称 | 目标 | 交付物 | 预估 |
|-------|------|------|--------|------|
| 1 | Skill Definition | 数据模型+Schema | SkillDefinition、SkillDAG | 2d |
| 2 | Skill Executor | 执行引擎 | SkillRuntime、并行执行 | 3d |
| 3 | Tool Chain | Tool 间数据传递 | DataMapping、表达式引擎 | 2d |
| 4 | Skill Validation | 定义验证 | SkillValidator、依赖检查 | 1d |
| 5 | SDK Integration | SDK 封装 | runtime.run_skill() | 2d |

## 4. 接口设计

```python
skill = SkillDefinition(
    name="web-research",
    tools=["search", "browser"],
    execution_graph=SkillDAG(steps=[
        SkillStep(tool="search", input_mapping={"query": "$input.topic"}),
        SkillStep(tool="browser", input_mapping={"url": "$search_result.top_url"}),
    ]),
)
result = await runtime.run_skill("web-research", {"topic": "AI trends"})
```
