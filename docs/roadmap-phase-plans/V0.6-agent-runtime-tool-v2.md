# V0.6 Agent Runtime — Tool Runtime v2

> **注意**：本文档基于路线图推演，实际实现可能不同。V0.6 从原"Function Calling Runtime"重定义为"Tool Runtime v2"。

## 1. 概述

- **目标**：完整升级工具运行时，引入原生 tool_calls 支持、并行工具执行优化、流式工具结果和 Schema 版本管理
- **背景**：V0.3 的 Tool Runtime v1 基于文本解析 ReAct 循环，存在 JSON 解析失败风险和工具定义版本管理缺失。V0.6 在 V0.5 流水线基础上全面升级工具系统
- **状态**：📋 规划中

### 2.2 核心变更

#### 2.2.1 原生 Tool Calling

```python
# V0.6: 使用 LLM tools 参数替代文本解析
from langchain_core.messages import ToolMessage

# Tool schema 转换为 OpenAI/Anthropic 格式
def to_openai_tool(tool: BaseTool) -> dict:
    return {
        "type": "function",
        "function": {
            "name": tool.name,
            "description": tool.description,
            "parameters": tool.schema.parameters,
        }
    }

# LLM 调用时传入 tools
llm_with_tools = llm.bind_tools([to_openai_tool(t) for t in tools])
response = await llm_with_tools.ainvoke(messages)
# response.tool_calls → 结构化列表，无需 JSON 解析
```

#### 2.2.2 Schema 版本管理

```python
@dataclass
class ToolSchemaVersion:
    version: str           # 语义版本 "1.0.0"
    parameters: dict       # JSON Schema
    deprecated_params: list[str]  # 废弃参数
    migration_note: str    # 迁移说明

class VersionedTool(BaseTool):
    schema_versions: list[ToolSchemaVersion]

    @property
    def current_schema(self) -> ToolSchemaVersion:
        return self.schema_versions[-1]

    def get_schema(self, version: str) -> ToolSchemaVersion | None:
        for sv in self.schema_versions:
            if sv.version == version:
                return sv
        return None
```

#### 2.2.3 并行执行优化

```python
class ParallelToolExecutor:
    """改进的并行工具执行器，支持 per-tool 超时和结果排序"""

    async def execute_parallel(
        self,
        calls: list[ToolCall],
        timeout_ms: int = 30000,
    ) -> list[ToolResult]:
        tasks = []
        for call in calls:
            task = asyncio.create_task(
                self._execute_with_timeout(call, timeout_ms)
            )
            tasks.append(task)

        # 返回结果保持原始顺序
        results = await asyncio.gather(*tasks, return_exceptions=True)
        return [self._normalize_result(r) for r in results]
```

#### 2.2.4 流式工具结果

```python
# SSE 事件扩展
# tool.progress: 工具执行进度
# tool.output: 工具流式输出 delta
# tool.completed: 工具执行完成（含 summary）

async def execute_with_streaming(self, call: ToolCall) -> AsyncIterator[SseEvent]:
    yield SseEvent(type="tool.started", tool_call_id=call.id, tool=call.name)
    async for chunk in self._execute_stream(call):
        yield SseEvent(type="tool.output", tool_call_id=call.id, delta=chunk)
    yield SseEvent(type="tool.completed", tool_call_id=call.id, result=...)
```

## 7. 风险与注意事项

- **Provider 兼容性**：不同 LLM Provider 的 tool calling 格式有差异，需要适配层
- **JSON Mode 移除风险**：原 agent_node 依赖 JSON Mode 进行路由决策，切换 native tool calling 后需重新设计路由逻辑
- **Schema 迁移**：已有工具定义需要版本化改造，不能破坏现有功能
