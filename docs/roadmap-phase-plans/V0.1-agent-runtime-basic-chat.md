# V0.1 Agent Runtime — 基础对话 + SSE 全链路流式响应

## 1. 概述

- **目标**：建立 Winter Agent 的基础对话能力，实现从 LLM 到浏览器的 token 级 SSE 全链路流式传输
- **背景**：作为整个项目的第一块基石，V0.1 搭建了三层架构骨架（React 前端 → Spring Boot BFF → Python AI 服务），实现了端到端的流式对话
- **状态**：✅ 已完成

## 2. 技术方案

### 2.1 架构概览

```
┌──────────────────────────────────────────────────────────┐
│ React 前端 (port 3000)                                    │
│  ChatInput → useChat → fetch('/api/chat/stream')         │
│          ↓ SSE ReadableStream reader                     │
│          ↓ handleParsedEvent() → 状态更新 → 渲染          │
└──────────────────────────────────────────────────────────┘
                         │ HTTP POST /api/chat/stream
                         ▼
┌──────────────────────────────────────────────────────────┐
│ Spring Boot BFF (port 8080)                              │
│  ChatController → WebClient proxy → AI Service           │
│          JWT 认证 (JwtAuthFilter)                         │
│          SSE 透传 (ServerSentEvent → Flux)               │
└──────────────────────────────────────────────────────────┘
                         │ HTTP/SSE
                         ▼
┌──────────────────────────────────────────────────────────┐
│ Python AI 服务 (port 8000)                               │
│  FastAPI → /api/v1/generate/stream                       │
│          LangGraph ReAct Agent → LLM API                 │
│          SSE 事件流 (token/tool_start/tool_result/...)    │
└──────────────────────────────────────────────────────────┘
```

### 2.4 关键代码路径

**流式对话全链路**：

1. 用户输入 → `ChatInput.handleSubmit()` → `onSend(message)`
2. `useChat.sendMessage()` → `fetch('/api/chat/stream', { method: 'POST', body: { message, conversationId } })`  
   - 文件: `frontend/src/hooks/useChat.ts:147-176`
3. Spring Boot `ChatController` 接收请求 → `AIClient` 通过 WebClient 代理到 Python AI 服务
   - 文件: `backend/src/main/java/.../controller/ChatController.java`
4. Python FastAPI `/api/v1/generate/stream` → LangGraph ReAct Agent 调用 LLM
   - LLM 返回 token 流 → 封装为 SSE 事件 → `StreamingResponse`
5. 前端 `response.body.getReader()` 逐块读取 SSE
   - 文件: `frontend/src/hooks/useChat.ts:181-184`
6. `decoder.decode()` → 按 `\n` 分割 → 解析 `data:` 行 → JSON.parse → `handleParsedEvent()`
   - 文件: `frontend/src/hooks/useChat.ts:191-255`
7. 事件分发：`token` → `assistantContent += text` → `updateMessage()` → React 重新渲染
8. 流结束 → `setIsSending(false)`

**新版 SSE 协议（chatApi.ts）**：
```typescript
// frontend/src/features/ai-chat/services/chatApi.ts:29-81
export async function sendChatMessage(req: ChatRequest): Promise<void> {
  const response = await fetch('/api/chat/stream', { method: 'POST', ... });
  const reader = response.body.getReader();
  while (true) {
    const { done, value } = await reader.read();
    buffer += decoder.decode(value, { stream: true });
    // 按行解析 SSE: "data: {...}" → JSON.parse → handleEvent()
  }
}
```

新版事件类型更加丰富：`conversation.started`, `agent.started`, `agent.finished`, `tool.started`, `tool.finished`, `tool.failed`, `message.tool_call`, `message.delta`, `message.reasoning`, `message.done`, `conversation.finished`, `error`

## 7. 风险与注意事项

- **SSE 兼容性**：部分反向代理可能缓冲 SSE 响应，需要正确设置 `X-Accel-Buffering: no` 和 `Cache-Control: no-cache`
- **BFF 层必要性**：V0.1 的 BFF 主要做代理透传，复杂度较低，但为后续 JWT 认证和 API 聚合奠定了基础
- **LLM 依赖**：无 API_KEY 时系统进入 mock 模式（`/health` 返回 `mode: "mock"`），方便本地开发
- **流式光标动画**：使用 Tailwind `animate-pulse` 实现输入中闪烁光标 `▌`
