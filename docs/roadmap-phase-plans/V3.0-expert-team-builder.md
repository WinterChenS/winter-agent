# V3.0 Expert Team — Team Builder

## 1. 概述

- **目标**：可视化团队构建器，自定义专家团队和组织管理
- **状态**：📋 规划中

## 2. 技术方案

- 成员拖拽加入团队
- 角色配置面板
- Leader 指定
- 通信规则配置
- 团队模板库
