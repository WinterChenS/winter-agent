# V0.3 Agent Runtime — Tool Runtime v1（ReAct + Tool Registry + Strategy Guard）

## 1. 概述

- **目标**：建立完整的 Tool Runtime 基础设施，包括工具注册表（Registry）、ReAct 循环集成和策略门控（Strategy Guard）
- **背景**：V0.2 实现了 LangGraph 图结构，但 tool_node 只支持硬编码的工具调用。V0.3 引入可扩展的工具系统架构
- **状态**：✅ 已完成

### 2.3 关键数据结构

**BaseTool 接口**（`ai_service/tools/base.py`）：
```python
class BaseTool(ABC):
    name: str                    # 工具唯一名称（注册键）
    description: str             # LLM 可读的描述
    input_schema: dict           # 输入参数 JSON Schema
    output_schema: dict = {}     # 输出结构
    version: str = "1.0.0"       # 语义版本
    timeout_ms: int = 30000      # 超时（ms）
    retry_policy: dict = {"max_retries": 0}
    policy_tags: list[str] = []  # 策略标签
    schema: ToolSchema | None    # OpenAI FC 兼容 schema

    @abstractmethod
    async def execute(self, input_payload: Mapping[str, Any]) -> ToolResult:
        """执行工具"""
```

**ToolResult**（`ai_service/tools/base.py:24`）：
```python
@dataclass(slots=True)
class ToolResult:
    ok: bool
    data: Any = None
    error: ToolError | None = None

    @classmethod
    def success(cls, data: Any) -> "ToolResult": ...
    @classmethod
    def failure(cls, code: str, message: str, retryable: bool = False) -> "ToolResult": ...
    def to_dict(self) -> dict: ...
```

**ToolRegistry**（`ai_service/tools/registry.py:24`）：
```python
class ToolRegistry:
    def register(self, tool: BaseTool) -> None   # 注册工具（重复抛异常）
    def get(self, name: str) -> BaseTool          # 查找工具
    def invoke(self, name, input) -> dict         # 调用工具
    def discover(self) -> None                    # 自动发现 @tool 子类
    def list_tools(self) -> list[dict]            # 列出所有工具
    def list_capabilities(self) -> list[dict]     # 列出能力（含版本/策略）
    def build_tools_prompt(self) -> str           # 构建工具提示词
```

**PolicyGate**（`ai_service/policy/gate.py:10`）：
```python
@dataclass(slots=True)
class PolicyGate:
    tool_whitelist: set[str]     # 工具白名单（空=全部允许）
    max_query_len: int = 500     # 查询最大长度
    timeout_override_ms: int | None = None  # 超时覆盖

    def evaluate(self, call: CapabilityCall, context: PolicyContext) -> PolicyDecision:
        # 1. 白名单检查 → deny (POLICY_TOOL_NOT_ALLOWED)
        # 2. 查询长度检查 → deny (POLICY_QUERY_TOO_LONG)
        # 3. 通过 → allow
```

### 2.4 关键代码路径

**工具自动发现流程**（`ai_service/tools/registry.py:65`）：
1. `registry.discover()` 调用
2. 遍历 `BaseTool.__subclasses__()`
3. 检查 `_is_tool = True`（`@tool` 装饰器设置）
4. 验证 `schema.parameters` 非空且有 `properties`
5. 实例化并 `register()`

**ReAct + 策略门控集成**（`ai_service/graph/nodes.py:69,528`）：
```python
# agent_node 构建策略门控
gate = _build_policy_gate()
# 从 settings 读取:
#   policy_tool_whitelist → whitelist set
#   policy_max_query_len → max_query_len
#   policy_timeout_override_ms → timeout_override_ms

# tool_node 执行时通过门控
decision = gate.evaluate(call, context=context)
if decision.action != "allow":
    return {"result": {"ok": False, "error": {..., "code": "POLICY_DENIED"}}}
```

## 4. 接口设计

### 工具注册 API

```python
# 定义工具
@tool
class MyTool(BaseTool):
    name = "my_tool"
    description = "Does something useful"
    input_schema = {
        "type": "object",
        "properties": {"param1": {"type": "string"}},
        "required": ["param1"],
    }
    schema = ToolSchema(parameters=input_schema)

    async def execute(self, input_payload: Mapping[str, Any]) -> ToolResult:
        return ToolResult.success({"result": "done"})

# 注册和调用
registry = ToolRegistry()
registry.register(MyTool())
result = await registry.invoke("my_tool", {"param1": "value"})
```

## 6. 验收标准

- [ ] AC1: `ToolRegistry.discover()` 从代码中自动发现所有 `@tool` 标记的工具类
- [ ] AC2: 每个工具根据 JSON Schema 校验输入参数
- [ ] AC3: `agent_node` 能通过 ReAct 循环调用工具并处理结果
- [ ] AC4: PolicyGate 拦截白名单外的工具、超长查询、连续搜索

- [ ] AC6: `build_tools_prompt()` 输出格式化的 LLM 工具提示

## 7. 风险与注意事项

- **工具发现依赖继承链**：`BaseTool.__subclasses__()` 只在工具类被 import 后才能发现，需确保所有工具在 registry.discover() 前加载
- **PolicyGate 粒度**：当前只支持白名单/查询长度/超时三种策略，不支持基于 Agent 角色的差异化策略
- **CodeSandbox 安全**：subprocess 执行任意代码，依赖资源限制（`RLIMIT_AS`）而非沙箱隔离
- **MinIO 上传**：Sandbox 中生成的图片通过 MinIO 上传，需确认服务可用
