# V1.8 Knowledge Engine — Hybrid Search

> **注意**：本文档基于路线图推演，实际实现可能不同。

## 1. 概述

- **目标**：实现全文搜索 + 向量语义搜索 + 元数据过滤的混合检索引擎
- **背景**：V1.7 完成了多模态知识抽取。V1.8 使知识可被高效检索，支持关键词匹配和语义理解的融合排序
- **状态**：📋 规划中

## 2. 技术方案

### 2.1 架构

### 2.2 核心组件

| 组件 | 职责 | 技术选型 |
|------|------|---------|
| `FullTextSearch` | BM25 关键词检索 | Elasticsearch / PostgreSQL tsvector |
| `VectorSearch` | 语义相似度搜索 | Milvus / pgvector |
| `MetadataFilter` | 元数据精确过滤 | PostgreSQL JSONB |
| `QueryProcessor` | 查询重写+扩展+向量化 | LLM + Embedding Model |
| `FusionRanker` | 多路召回融合排序 | RRF (Reciprocal Rank Fusion) |
| `SearchOrchestrator` | 协调多路搜索+融合 | FastAPI service |

### 2.3 关键数据结构

```python
@dataclass
class SearchRequest:
    query: str
    top_k: int = 10
    filters: dict | None = None       # {"format": "pdf", "date_range": ...}
    search_modes: list[str] = ["fulltext", "vector", "metadata"]
    fusion_method: str = "rrf"        # rrf | weighted_sum

@dataclass
class SearchResult:
    chunk_id: str
    doc_id: str
    content: str
    score: float                      # 融合后的分数
    scores: dict[str, float]          # 各路分数
    highlights: list[str]             # 关键词高亮
    metadata: dict
```

### 2.4 融合排序 (RRF)

```python
class FusionRanker:
    def reciprocal_rank_fusion(
        self,
        result_sets: dict[str, list[SearchResult]],
        k: int = 60,
    ) -> list[SearchResult]:
        """RRF: score = sum(1 / (k + rank_i)) for each result set"""
        scores: dict[str, float] = {}
        for source, results in result_sets.items():
            for rank, result in enumerate(results):
                scores[result.chunk_id] = scores.get(result.chunk_id, 0) + 1 / (k + rank + 1)

        # 排序并附加 scores
        merged = []
        for chunk_id, score in sorted(scores.items(), key=lambda x: -x[1]):
            result = self._find_result(chunk_id, result_sets)
            result.score = score
            merged.append(result)

        return merged[:top_k]
```

## 3. Phase 拆分

| Phase | 名称 | 目标 | 关键交付物 | 预估 |
|-------|------|------|-----------|------|
| 1 | Full-Text Search | BM25 关键词检索 | Elasticsearch/tsvector 集成 | 3d |
| 2 | Vector Search | 语义向量搜索 | Milvus/pgvector + Embedding | 3d |
| 3 | Metadata Filter | 元数据精确过滤 | JSONB 查询 API | 2d |
| 4 | Query Processor | 查询重写+向量化 | LLM Query Rewriter、Embedding | 3d |
| 5 | Fusion Ranker | RRF 融合排序 | FusionRanker、权重调优 | 2d |
| 6 | Search API | 统一搜索 API | SearchOrchestrator、REST API | 2d |
