# V2.2 Skill Engine — Skill Registry

> **注意**：本文档基于路线图推演，实际实现可能不同。

## 1. 概述

- **目标**：实现 Skill 注册中心，支持版本管理、权限控制和配置管理
- **状态**：📋 规划中

## 2. 技术方案

```python
class SkillRegistry:
    def register(self, skill: SkillDefinition) -> str   # 返回 skill_id
    def get(self, skill_id: str, version: str = "latest") -> SkillDefinition
    def list(self, filters: dict) -> list[SkillSummary]
    def deprecate(self, skill_id: str, version: str)
    def set_permissions(self, skill_id: str, acl: AccessControl)

class SkillVersionManager:
    def publish(self, skill_id: str, version: str)     # 发布新版本
    def rollback(self, skill_id: str, version: str)    # 回滚到指定版本
    def diff(self, skill_id: str, v1: str, v2: str)    # 版本对比
```

### 权限模型

```python
@dataclass
class SkillAccess:
    skill_id: str
    visibility: str         # public | workspace | private
    allowed_roles: list[str] # admin | editor | viewer
    rate_limit: int | None   # 每分钟调用限制
```

## 4. 接口设计

| 方法 | 路径 | 说明 |
|------|------|------|
| `POST` | `/v1/skills` | 注册 Skill |
| `GET` | `/v1/skills/{id}` | 获取 Skill |
| `GET` | `/v1/skills/{id}/versions` | 版本列表 |
| `PUT` | `/v1/skills/{id}/permissions` | 设置权限 |
