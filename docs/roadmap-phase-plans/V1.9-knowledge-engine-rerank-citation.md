## 2. 技术方案

### 2.1 ReRank

采用 Cross-Encoder 模型对搜索结果重排序：

```python
class CrossEncoderReranker:
    def __init__(self, model: str = "BAAI/bge-reranker-v2-m3"):
        self.model = CrossEncoder(model)

    def rerank(
        self, query: str, candidates: list[SearchResult], top_k: int = 5
    ) -> list[SearchResult]:
        pairs = [(query, c.content) for c in candidates]
        scores = self.model.predict(pairs)
        # 按重排分数排序
        ranked = sorted(
            zip(candidates, scores), key=lambda x: -x[1]
        )
        for result, score in ranked[:top_k]:
            result.rerank_score = float(score)
        return [r for r, _ in ranked[:top_k]]
```

### 2.3 Knowledge Cache

```python
class KnowledgeCache:
    def __init__(self, redis_client, ttl: int = 3600):
        self.redis = redis_client
        self.ttl = ttl

    async def get_or_compute(
        self, query_embedding: list[float], top_k: int
    ) -> list[SearchResult]:
        """向量相似查询缓存：相同 query embedding 命中缓存直接返回"""
        cache_key = self._hash_embedding(query_embedding)
        cached = await self.redis.get(cache_key)
        if cached:
            return json.loads(cached)
        results = await self.searcher.search(query_embedding, top_k)
        await self.redis.setex(cache_key, self.ttl, json.dumps(results))
        return results
```

## 3. Phase 拆分

| Phase | 名称 | 目标 | 关键交付物 | 预估 |
|-------|------|------|-----------|------|
| 1 | Cross-Encoder Rerank | 搜索结果精排 | CrossEncoderReranker | 2d |
| 2 | Citation System | 来源引用标注 | CitationGenerator、前端引用展示 | 3d |
| 3 | Embedding Cache | 向量查询缓存 | Redis KnowledgeCache | 2d |
| 4 | LLM Response Cache | 常见问题回答缓存 | Semantic cache（相似问题命中） | 2d |
| 5 | Rerank Model Serving | 模型部署优化 | ONNX/TensorRT 推理加速 | 2d |
