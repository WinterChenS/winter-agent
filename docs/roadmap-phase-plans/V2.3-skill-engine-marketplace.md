# V2.3 Skill Engine — Skill Marketplace

> **注意**：本文档基于路线图推演，实际实现可能不同。

## 1. 概述

- **目标**：建立技能市场，支持 Skill 的发布、发现、安装和评价
- **状态**：📋 规划中

## 2. 技术方案

```python
@dataclass
class SkillListing:
    skill_id: str
    publisher: str
    name: str
    description: str
    category: str           # 分类标签
    rating: float           # 评分 (0-5)
    downloads: int
    verified: bool          # 官方认证
    price: str              # free | paid

class Marketplace:
    async def search(self, query: str, filters: dict) -> list[SkillListing]
    async def install(self, skill_id: str, workspace_id: str) -> InstallResult
    async def publish(self, skill: SkillDefinition, listing: SkillListing)
    async def review(self, skill_id: str, rating: int, comment: str)
```

## 3. Phase 拆分

| Phase | 名称 | 目标 | 预估 |
|-------|------|------|------|
| 1 | Listing Store | Skill 列表存储 | 2d |
| 2 | Search + Discovery | 分类/搜索/推荐 | 2d |
| 3 | Install Flow | 一键安装到 Workspace | 2d |
| 4 | Rating + Review | 评分评价系统 | 2d |
| 5 | Marketplace UI | 前端市场界面 | 3d |
