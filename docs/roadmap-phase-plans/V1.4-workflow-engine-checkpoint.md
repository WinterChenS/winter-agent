# V1.4 Workflow Engine — Checkpoint & Resume

> **注意**：本文档基于路线图推演，实际实现可能不同。

## 1. 概述

- **目标**：实现 Workflow 级的状态快照、失败重试、补偿机制和断点恢复，确保长时间运行的 Workflow 可靠完成
- **背景**：V1.3 引入了 Human-in-the-loop（天然需要暂停/恢复）。V1.4 将暂停恢复能力推广到所有 Workflow 节点，实现企业级的故障恢复
- **状态**：📋 规划中

### 2.3 关键数据结构

@dataclass
class WorkflowCheckpoint:
    """Workflow 执行快照"""
    checkpoint_id: str
    workflow_run_id: str
    workflow_def_id: str
    state: str                      # "running" | "paused" | "failed" | "completed"
    current_level: int              # 当前执行层级

    retry_counts: dict[str, int]    # 每个节点的重试次数
    created_at: float

@dataclass
class RetryPolicy:
    max_retries: int = 3
    backoff_multiplier: float = 2.0
    initial_delay_seconds: int = 1
    max_delay_seconds: int = 300
    retryable_errors: list[str]     # 可重试的错误码

@dataclass
class CompensationAction:
    """Saga 补偿动作"""
    node_id: str
    action: str                     # "rollback" | "compensate" | "ignore"
    handler: str                    # 补偿函数引用
    params: dict

### 2.4 Checkpoint 机制

```python
class CheckpointManager:
    async def save(self, run_id: str, state: WorkflowState) -> str:
        """保存 Workflow 快照，返回 checkpoint_id"""
        checkpoint = WorkflowCheckpoint(
            checkpoint_id=uuid4().hex,
            workflow_run_id=run_id,
            state=state.status,
            node_results=state.node_results,
            pending_nodes=self._get_pending_nodes(state),
            context=state.context,
            created_at=time.time(),
        )
        await self.db.insert("workflow_checkpoints", checkpoint)
        return checkpoint.checkpoint_id

    async def load(self, run_id: str) -> WorkflowCheckpoint:
        """加载最近的 checkpoint"""
        return await self.db.find_one(
            "workflow_checkpoints",
            {"workflow_run_id": run_id},
            order_by="created_at DESC",
        )

    async def cleanup(self, run_id: str, keep_last: int = 3):
        """清理旧 checkpoint，保留最近 N 个"""
        await self.db.delete(
            "workflow_checkpoints",
            {"workflow_run_id": run_id},
            keep_latest=keep_last,
        )
```

### 2.5 重试与熔断

```python
class RetryEngine:
    def __init__(self):
        self._circuit_breakers: dict[str, CircuitBreaker] = {}

    async def execute_with_retry(
        self, node_id: str, operation: Callable, policy: RetryPolicy
    ) -> NodeResult:
        breaker = self._circuit_breakers.setdefault(
            node_id, CircuitBreaker(failure_threshold=5, recovery_timeout=30)
        )

        if breaker.is_open():
            raise CircuitBreakerOpenError(node_id)

        for attempt in range(policy.max_retries + 1):
            try:
                result = await operation()
                breaker.record_success()
                return result
            except RetryableError as e:
                breaker.record_failure()
                if attempt == policy.max_retries:
                    raise MaxRetriesExceededError(e)
                delay = min(
                    policy.initial_delay_seconds * (policy.backoff_multiplier ** attempt),
                    policy.max_delay_seconds,
                )
                await asyncio.sleep(delay)
```

### 2.6 Saga 补偿模式

```python
class CompensationManager:
    async def compensate(
        self, run_id: str, failed_node_id: str, completed_nodes: list[str]
    ) -> CompensationResult:
        """执行 Saga 补偿：回滚已完成节点"""
        compensations = []
        for node_id in reversed(completed_nodes):
            action = self._get_compensation_action(node_id)
            if action.action == "rollback":
                try:
                    await self._execute_rollback(node_id, action)
                    compensations.append({"node": node_id, "status": "rolled_back"})
                except Exception as e:
                    compensations.append({"node": node_id, "status": "failed", "error": str(e)})
        return CompensationResult(actions=compensations)
```

### 2.7 断点恢复

```python
class ResumeManager:
    async def resume(self, run_id: str) -> WorkflowResult:
        """从最近的 checkpoint 恢复 Workflow 执行"""
        checkpoint = await self.checkpoint_manager.load(run_id)
        if not checkpoint:
            raise NoCheckpointFoundError(run_id)

        # 确定下一个要执行的节点
        next_nodes = checkpoint.pending_nodes

        # 跳过已完成的节点
        remaining = [
            n for n in next_nodes
            if n not in checkpoint.node_results
        ]

        # 从当前层级继续执行
        return await self.executor.execute_from_level(
            workflow_def_id=checkpoint.workflow_def_id,
            start_level=checkpoint.current_level,
            skip_nodes=set(checkpoint.node_results.keys()),
            context=checkpoint.context,
        )
```

## 3. Phase 拆分

## 6. 验收标准

- [ ] AC1: Workflow 执行中每 N 个节点自动保存 checkpoint
- [ ] AC2: 节点执行失败自动重试（最多 3 次，指数退避）
- [ ] AC3: 连续失败 5 次触发熔断，后续请求直接失败
- [ ] AC4: Saga 补偿正确回滚已完成的节点
- [ ] AC5: 从 checkpoint 恢复后跳过已完成节点继续执行
- [ ] AC6: 前端显示 Workflow 运行状态和失败节点详情

## 7. 风险与注意事项

- **Checkpoint 频率**：频繁存快照影响性能，间隔太大恢复成本高，需要平衡
- **补偿不完全**：某些操作无法简单回滚（如已发送的邮件），需标记为 "compensate" 而非 "rollback"
- **幂等性**：恢复后重放节点可能产生副作用，节点实现需保证幂等
