## 2. 技术方案

### 2.2 核心组件

| 组件 | 职责 | 技术选型 |
|------|------|---------|
| `OCREngine` | 图片/PDF 文字识别 | Tesseract + PaddleOCR (中文) |
| `TableDetector` | 图片中表格检测和结构识别 | Table Transformer (Microsoft) |
| `ImageCaptioner` | 图片内容描述生成 | Vision LLM (GPT-4V / Claude Vision) |
| `MultiModalExtractor` | 图文混合文档的信息抽取 | LayoutLMv3 / Donut |
| `ImagePreprocessor` | 图片预处理（去噪、增强） | OpenCV、Pillow |

### 2.3 多模态知识抽取流程

```python
class MultiModalExtractor:
    async def extract(self, document: ParsedDocument) -> MultiModalResult:
        texts = []
        tables = []
        images = []

        for page in document.pages:
            # 1. 图片区域检测
            regions = await self.layout_detector.detect(page.image)

            for region in regions:
                if region.type == "text":
                    text = await self.ocr.extract(region.crop())
                    texts.append(text)
                elif region.type == "table":
                    table = await self.table_detector.extract(region.crop())
                    tables.append(table)
                elif region.type == "figure":
                    caption = await self.image_captioner.describe(region.crop())
                    images.append({"region": region, "caption": caption})

        return MultiModalResult(texts=texts, tables=tables, images=images)
```
