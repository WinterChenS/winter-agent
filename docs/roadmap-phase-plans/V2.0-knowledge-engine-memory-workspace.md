# V2.0 Knowledge Engine — 长期 Memory + 企业知识库 + Workspace 隔离

> **注意**：本文档基于路线图推演，实际实现可能不同。

## 1. 概述

- **目标**：实现长期记忆系统、企业级知识库和 Workspace 隔离，完成 Knowledge Engine 阶段的最终里程碑

### 2.2 Memory 管理

```python
@dataclass
class Memory:
    memory_id: str
    type: str                   # episodic | semantic | procedural
    user_id: str
    workspace_id: str
    content: str
    importance: float           # 记忆重要性评分 (0-1)
    access_count: int           # 被检索次数
    last_accessed: float
    created_at: float
    expires_at: float | None    # None = 永久
    embedding: list[float]

class MemoryManager:
    async def remember(self, memory: Memory):
        """存储新记忆（带重要性评分）"""
        memory.importance = await self._score_importance(memory)
        await self.vector_store.upsert(memory)

    async def recall(
        self, query: str, user_id: str, top_k: int = 5
    ) -> list[Memory]:
        """检索相关记忆（向量搜索 + 重要性加权 + 时间衰减）"""
        results = await self.vector_store.search(
            query_embedding=await self.embed(query),
            filter={"user_id": user_id},
            top_k=top_k * 2,
        )
        # 重要性加权 + 时间衰减
        for r in results:
            r.score *= (0.5 + 0.5 * r.importance)  # 重要性加权
            age_days = (time.time() - r.last_accessed) / 86400
            r.score *= math.exp(-0.01 * age_days)   # 时间衰减
        return sorted(results, key=lambda r: -r.score)[:top_k]

    async def forget(self, memory_id: str):
        """遗忘指定记忆"""
        await self.vector_store.delete(memory_id)

    async def consolidate(self, user_id: str):
        """记忆巩固：将最近的 episodic memories 提炼为 semantic memories"""
        recent = await self.get_recent_episodic(user_id, days=7)
        consolidated = await self.llm_consolidate(recent)
        for memory in consolidated:
            memory.type = "semantic"
            await self.remember(memory)
```

### 2.4 Workspace 隔离

```python
@dataclass
class Workspace:
    workspace_id: str
    name: str
    members: list[WorkspaceMember]
    knowledge_bases: list[str]   # 关联知识库 ID
    agents: list[str]            # 关联 Agent ID
    settings: WorkspaceSettings
    created_at: float

@dataclass
class WorkspaceMember:
    user_id: str
    role: str                    # admin | editor | viewer
    joined_at: float

class WorkspaceIsolation:
    """确保跨 Workspace 的数据隔离"""
    async def enforce(self, user_id: str, workspace_id: str) -> bool:
        member = await self.get_member(user_id, workspace_id)
        if not member:
            raise WorkspaceAccessDenied(user_id, workspace_id)
        return True

    async def scope_search(
        self, query: str, workspace_id: str
    ) -> list[SearchResult]:
        """搜索仅限当前 Workspace 的知识库"""
        kb_ids = await self.get_workspace_kbs(workspace_id)
        return await self.searcher.search(query, filter={"kb_id": {"$in": kb_ids}})
```

## 3. Phase 拆分

| Phase | 名称 | 目标 | 关键交付物 | 预估 |
|-------|------|------|-----------|------|
| 1 | Memory Store | 记忆向量存储+检索 | MemoryManager、向量存储 | 3d |
| 2 | Memory Consolidation | 短期→长期记忆提炼 | LLM Consolidator | 3d |
| 3 | Knowledge Base | 知识库 CRUD | KnowledgeBase API | 3d |
| 4 | Workspace | 多租户隔离 | Workspace、AccessControl | 3d |
| 5 | Memory UI | 记忆管理界面 | 前端 Memory 面板 | 2d |
| 6 | KB Management UI | 知识库管理界面 | 前端 KB 管理 | 2d |
