# V2.5 Skill Engine — Skill Sharing & Import/Export

> **注意**：本文档基于路线图推演，实际实现可能不同。

## 1. 概述

- **目标**：实现 Skill 的导入/导出和跨 Workspace 共享
- **状态**：📋 规划中

## 2. 技术方案

### 导出格式

```yaml
# skill-export.yaml
name: web-research
version: 1.0.0
tools: [search, browser]
execution_graph:
  steps:
    - tool: search
      input_mapping: {query: "$input.topic"}
    - tool: browser
      input_mapping: {url: "$search_result.top_url"}
input_schema:
  type: object
  properties: {topic: {type: string}}
output_schema:
  type: object
  properties: {summary: {type: string}, sources: {type: array}}
```

### 共享方式

| 方式 | 说明 |
|------|------|
| YAML Export | 导出为 YAML 文件 |
| Share Link | 生成分享链接（指定 Workspace/Public） |
| Marketplace Publish | 发布到 Skill Marketplace |
| Git Sync | Git 仓库同步（版本管理） |
