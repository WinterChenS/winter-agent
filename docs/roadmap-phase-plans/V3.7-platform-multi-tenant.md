# V3.7 Platform — Multi Tenant

> 基于路线图推演 | 📋 规划中

多租户架构：
- Tenant/Workspace 数据隔离
- RBAC（Admin/Editor/Viewer + 自定义角色）
- SSO 集成（OIDC/SAML）
- 资源配额（Agent/Workflow/Document 数量限制）
- 跨 Workspace 共享策略

```python
@dataclass
class Tenant:
    tenant_id: str
    name: str
    workspaces: list[Workspace]
    subscription: SubscriptionTier  # free/pro/enterprise
    quotas: ResourceQuota
```

Phase: Tenant Model(2d) → RBAC(3d) → SSO(3d) → Quota System(2d) → Cross-Tenant(2d)
