# V0.4 Agent Runtime — 多 Agent 路由 + 顺序/并行/Supervisor 协作模式

## 1. 概述

- **目标**：实现多智能体编排，支持关键词+LLM 兜底路由和三种协作策略（顺序链/并行扇出/监督分解合成）
- **背景**：V0.3 的 ReAct Agent 只能处理单一对话流。V0.4 引入 Agent 管理系统和多智能体协作能力
- **状态**：✅ 已完成

class AgentDefinition(BaseModel):

class RouterResult:
    agents: list[AgentDefinition]  # 选中的 Agent（1-3个）
    strategy: str                  # sequential | parallel | supervisor
    source: str                    # "keyword" | "llm" | "none"

ROUTER_SYSTEM_PROMPT:  # LLM 路由提示词

### 2.4 关键代码路径

**路由决策流程**（`ai_service/core/router_agent.py:48`）：
1. `route(user_query)` 调用
2. 获取所有已启用的 Agent → `repository.list_enabled()`
3. **关键词匹配**（`_keyword_match`）：
   - 将查询转为小写
   - 遍历 Agent 的 `trigger_keywords`
   - 按命中次数 + 优先级排序，取 Top 3
   - 策略：单 Agent → 其 `collaboration_strategy`；多 Agent 且策略一致 → 该策略；不一致 → `parallel`
4. **LLM 兜底**（`_llm_route`）：
   - 关键词未命中时，构建 Agent 描述列表
   - 调用 LLM JSON Mode 选择最佳 Agent
   - 温度=0，确保确定性路由

**AgentFactory 组装流程**（`ai_service/core/agent_factory.py:32`）：
1. 渲染系统提示模板（`{current_time}` 等变量替换）
2. 从 ToolRegistry 解析工具名称 → 实例
3. 根据 definition.model_params 初始化 ChatOpenAI
4. 返回完整的 AgentRuntime

**三种协作策略**：

| 策略 | 行为 | 适用场景 |
|------|------|---------|
| `sequential` | Agent 按顺序链式执行，输出传递给下一个 | 简单问题、单 Agent |
| `parallel` | 多个 Agent 并发执行，结果汇总 | 需要多角度分析 |
| `supervisor` | Supervisor 分解任务 → 子 Agent 执行 → 合成结果 | 复杂协调任务 |

## 7. 风险与注意事项

- **关键词匹配不精确**：简单小写匹配无法处理同义词和语境，依赖 LLM 兜底
- **Router 提示词注入**：Agent 描述包含在 Router 提示词中，恶意 Agent 可能注入指令
- **Clone 名称冲突**：克隆使用 `name-copy` / `name-copy2` 递增模式，并发克隆可能冲突
- **Supervisor 策略复杂**：Supervisor 模式的实现复杂度最高，需要子任务分解和结果合成逻辑
