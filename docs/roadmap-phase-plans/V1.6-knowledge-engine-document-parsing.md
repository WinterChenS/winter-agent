# V1.6 Knowledge Engine — 文档上传与解析

> **注意**：本文档基于路线图推演，实际实现可能不同。

## 1. 概述

- **目标**：实现多格式文档上传和内容解析（PDF、Word、Excel、PPT、Markdown），提取结构化文本和元数据
- **背景**：Workflow Engine 完成后，Agent 需要基于企业文档进行知识工作。V1.6 建立文档处理管线
- **状态**：📋 规划中

## 2. 技术方案

### 2.1 架构

```
Upload → Format Detection → Parser Selection → Text Extraction → Chunking → Storage
  │           │                │                    │              │          │
  │      ┌────┴────┐    ┌──────┴──────┐    ┌───────┴──────┐  ┌────┴────┐ ┌──┴──┐
  │      │PDF      │    │PyMuPDF      │    │Text blocks    │  │Fixed    │ │PG   │
  │      │Word     │    │python-docx  │    │Tables         │  │Recursive│ │MinIO│
  └──────│Excel    │    │openpyxl     │    │Images(跳过)   │  │Semantic │ │VecDB│
         │PPT      │    │pptx         │    │Metadata       │  │Sliding  │      │
         │Markdown │    │mistune      │    │               │  │         │      │
         └─────────┘    └─────────────┘    └───────────────┘  └─────────┘      │
```

### 2.2 核心组件

| 组件 | 职责 | 技术选型 |
|------|------|---------|
| `DocumentUploader` | 文件上传、格式验证、大小限制 | FastAPI UploadFile |
| `FormatDetector` | MIME 类型检测 | python-magic |
| `PDFParser` | PDF 文本/表格提取 | PyMuPDF (fitz) |
| `WordParser` | .docx 解析 | python-docx |
| `ExcelParser` | .xlsx 表格提取 | openpyxl |
| `PPTParser` | .pptx 文本提取 | python-pptx |
| `MarkdownParser` | MD 结构解析 | mistune |
| `TextChunker` | 文本分块（固定/递归/语义） | LangChain TextSplitter |
| `DocumentStore` | 文档元数据和内容存储 | PostgreSQL + MinIO |

### 2.3 关键数据结构

```python
@dataclass
class ParsedDocument:
    doc_id: str
    filename: str
    format: str              # pdf/docx/xlsx/pptx/md
    file_size: int
    pages: int               # PDF 页数 / 等效页数
    text: str                # 提取的纯文本
    chunks: list[TextChunk]  # 分块结果
    tables: list[TableData]  # 提取的表格
    metadata: DocumentMeta   # 元数据
    created_at: float

@dataclass
class TextChunk:
    chunk_id: str
    doc_id: str
    content: str
    chunk_index: int
    page_range: tuple[int, int] | None
    token_count: int
    embedding: list[float] | None  # 向量化后填充

@dataclass
class TableData:
    table_id: str
    page: int
    headers: list[str]
    rows: list[list[str]]
    caption: str | None
```

## 3. Phase 拆分

| Phase | 名称 | 目标 | 关键交付物 | 预估 |
|-------|------|------|-----------|------|
| 1 | Upload + Detection | 文件上传+格式检测 | DocumentUploader、FormatDetector | 2d |
| 2 | PDF Parser | PDF 文本表格提取 | PDFParser (PyMuPDF) | 3d |
| 3 | Office Parsers | Word/Excel/PPT 解析 | 三种 Office 格式解析器 | 3d |
| 4 | Markdown Parser | MD 结构解析 | MarkdownParser、frontmatter 提取 | 1d |
| 5 | Text Chunking | 分块策略 | Fixed/Recursive/Semantic chunkers | 2d |
| 6 | Storage + API | 存储+查询 API | DocumentStore、CRUD API | 2d |

## 4. 接口设计

| 方法 | 路径 | 说明 |
|------|------|------|
| `POST` | `/v1/documents/upload` | 上传文档（multipart） |
| `GET` | `/v1/documents` | 文档列表 |
| `GET` | `/v1/documents/{id}` | 文档详情+分块 |
| `DELETE` | `/v1/documents/{id}` | 删除文档 |

## 5. 依赖关系

- **前置版本**：V1.5（Workflow Designer）
- **外部依赖**：PyMuPDF、python-docx、openpyxl、python-pptx、mistune

## 6. 验收标准

- [ ] AC1: PDF 上传后提取文本和表格，分块结果正确
- [ ] AC2: Word/Excel/PPT 各格式解析率 > 90%
- [ ] AC3: 大文件（50MB PDF）在 30s 内完成解析
- [ ] AC4: 分块后每个 chunk 保留 doc_id 和 page_range 溯源信息

## 7. 风险

- **PDF 复杂性**：扫描件 PDF 无文本层，需等待 V1.7 OCR 支持
- **表格提取精度**：复杂合并单元格表格提取准确率有限
