# V0.5 Agent Runtime — Plan-Execute-Synthesize 流水线 + ChartSpec 图表生成

## 1. 概述

- **目标**：实现结构化执行流水线（Planner → Executor → Synthesizer）和声明式 ChartSpec 图表生成系统
- **背景**：V0.4 实现了多 Agent 协作，但缺乏复杂的计划执行能力和数据可视化。V0.5 引入计划生成→顺序执行→结果合成的完整流水线，以及 ChartSpec → matplotlib 渲染 → MinIO 上传的图表管线
- **状态**：✅ 已完成

### 2.3 关键数据结构

**ChartSpec（新版，单数据源）**（`ai_service/chart/chart_spec.py:69`）：
```python
@dataclass
class ChartSpec:
    title: str                         # 图表标题
    chart_type: str                    # line|bar|pie|scatter|histogram|heatmap
    xlabel: str | None                 # X 轴标签
    ylabel: str | None                 # Y 轴标签
    figsize: tuple = (12, 6)          # 画布尺寸

    points: list[PointSpec] | None     # 散点图数据点

    labels: list[str] | None           # 类别标签

    def all_values(self) -> list[float] # 提取所有数值

@dataclass

    name: str           # 系列名称
    color: str          # 颜色 (#2F80ED)
    color_name: str     # 颜色中文名
    values: list[float] # 数据值
    axis: str = "left"  # 目标 y 轴 (left/right)
```

### 2.4 关键代码路径

**Plan-Execute-Synthesize 流程**：

1. **Planning**：`planning_node` 分析用户意图 → 生成结构化执行计划（步骤序列）
2. **Execution**：`tool_node` 顺序执行计划步骤（含图表代码生成 → sandbox 执行 → 验证 → 去重）
3. **Synthesis**：`composer_node` 收集所有执行结果 → 合成含嵌入图表标记 `[CHART:n]` 的综合报告
4. **Chart Planning**：`chart_planner_node` 从对话上下文提取数值数据 → 输出 `ChartSpec` 列表
5. **Answer Generation**：`answer_node` SSE 流式输出最终答案 + 图表标记

**图表渲染管线**：
1. `chart_planner_node` 提取图表数据 → `ChartSpec` 列表
2. `ChartSpec` 序列化为 JSON → 传给 sandbox 中的 Python 代码生成脚本
3. `CodeSandboxTool._build_preamble()` 预注入 `ChartTheme.initialize()`, `FontManager`, `Palette`, `MatplotlibRenderer`
4. Sandbox 执行 `MatplotlibRenderer.render(spec)` → 生成 PNG
5. 扫描输出 → `MinioStorage.upload_image()` → 返回 URL
6. `[CHART:n]` 标记嵌入最终文本 → 前端 `ChartRenderer` 解析并展示

## 7. 风险与注意事项

- **Sandbox 依赖**：图表代码在 subprocess 中执行，依赖 venv 中的 matplotlib/numpy 等库
- **ChartSpec 双版本共存**：`domain/chart_spec.py`（旧版 DataPoint）和 `chart/chart_spec.py`（新版 SeriesSpec）共存，存在迁移复杂度
- **SSE 图表事件时序**：图表数据通过 SSE 先于文本发送，前端需正确处理先收到 chart 事件再收到 `[CHART:n]` 标记的时序
- **MinIO 可用性**：MinIO 不可用时 sandbox 工具仍能执行但图片无法上传，chart URL 为空
- **去重与验证**：执行流水线中图表代码需验证正确性并去重，避免重复渲染
