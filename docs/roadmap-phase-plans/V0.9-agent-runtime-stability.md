### 2.3 Retry 策略

```python
@dataclass
class RetryPolicy:
    max_retries: int = 3
    base_delay_ms: int = 1000       # 初始延迟
    max_delay_ms: int = 30000       # 最大延迟
    backoff_multiplier: float = 2.0 # 退避因子
    jitter: bool = True             # 随机抖动
    retryable_errors: list[str]     # 可重试的错误码

class RetryEngine:
    async def execute_with_retry(
        self,
        operation: Callable,
        policy: RetryPolicy,
    ) -> Any:
        for attempt in range(policy.max_retries + 1):
            try:
                return await operation()
            except RetryableError as e:
                if attempt == policy.max_retries:
                    raise MaxRetriesExceededError(e)
                delay = min(
                    policy.base_delay_ms * (policy.backoff_multiplier ** attempt),
                    policy.max_delay_ms,
                )
                if policy.jitter:
                    delay *= random.uniform(0.5, 1.5)
                await asyncio.sleep(delay / 1000)
```

### 2.4 超时控制

```python
class TimeoutConfig:
    request_timeout_ms: int = 120000    # 单次请求总超时 2min
    node_timeout_ms: int = 60000        # 单个 graph node 超时 1min
    tool_timeout_ms: int = 30000        # 单个工具调用超时 30s
    llm_timeout_ms: int = 45000         # LLM 调用超时 45s

class TimeoutManager:
    async def with_timeout(
        self, coro, timeout_ms: int, timeout_type: str
    ) -> Any:
        try:
            return await asyncio.wait_for(coro, timeout=timeout_ms / 1000)
        except asyncio.TimeoutError:
            raise RuntimeTimeoutError(
                f"{timeout_type} exceeded {timeout_ms}ms limit"
            )
```

### 2.6 Checkpoint & Recovery

```python
@dataclass
class RuntimeCheckpoint:
    checkpoint_id: str
    conversation_id: str
    graph_state: State           # LangGraph State 快照
    iteration_count: int
    tool_results: dict[str, Any] # 工具结果缓存
    created_at: float

class CheckpointManager:
    async def save(
        self, conversation_id: str, state: State
    ) -> RuntimeCheckpoint: ...
    async def load(
        self, conversation_id: str
    ) -> RuntimeCheckpoint | None: ...
    async def list_checkpoints(
        self, conversation_id: str
    ) -> list[RuntimeCheckpoint]: ...

class RecoveryManager:
    async def recover(
        self, conversation_id: str
    ) -> RecoveryResult:
        checkpoint = await self.checkpoint_manager.load(conversation_id)
        if not checkpoint:
            return RecoveryResult.fresh()
        # 从 checkpoint 恢复 state，重新进入 graph
        return RecoveryResult.from_checkpoint(checkpoint)
```

## 6. 验收标准

- [ ] AC1: LLM 调用失败自动重试（最多 3 次，指数退避）
- [ ] AC2: 工具调用超时后优雅终止并返回部分结果
- [ ] AC3: 用户取消对话后所有异步任务在 5s 内终止
- [ ] AC4: 连续失败 5 次触发熔断，30s 后半开尝试
- [ ] AC5: 从 checkpoint 恢复后对话继续从断点执行
- [ ] AC6: PostgreSQL 故障不导致数据丢失（checkpoint 已持久化）

## 7. 风险与注意事项

- **取消不完全**：subprocess（sandbox）可能无法被 asyncio cancel 终止，需要进程级 kill
- **Checkpoint 性能**：频繁保存 state 可能影响延迟，需要平衡保存频率
- **幂等性**：恢复后重放工具调用可能产生副作用，需要确保工具幂等或缓存结果
- **LLM 缓存失效**：checkpoint 中的 LLM 响应可能因温度参数变化而不再适用
