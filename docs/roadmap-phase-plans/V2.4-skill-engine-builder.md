# V2.4 Skill Engine — 可视化 Skill Builder

> **注意**：本文档基于路线图推演，实际实现可能不同。

## 1. 概述

- **目标**：实现可视化 Skill Builder，拖拽 Tool 节点组合为 Skill
- **状态**：📋 规划中

## 2. 技术方案

复用 V1.5 Workflow Designer 的 ReactFlow 画布框架，定制为 Skill Builder：
- 节点类型：Tool 节点、Input 节点、Output 节点、Transform 节点
- 连线代表数据流
- 属性面板编辑 Tool 参数映射
- 实时预览 Skill 执行
